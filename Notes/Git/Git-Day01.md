# What is Git?

Git is a Distributed Version Control System (DVCS) used to track changes in source code over time.

It allows developers to:
- Track project history
- Restore previous versions
- Work safely without losing code
- Collaborate with other developers

---

# What is GitHub?

GitHub is a cloud-based platform that hosts Git repositories online.

It allows developers to:
- Store projects online
- Collaborate with teams
- Share code
- Manage issues and documentation

---

# Git vs GitHub

| Git | GitHub |
|------|---------|
| Version Control System | Cloud Hosting Platform |
| Works locally | Works online |
| Tracks changes | Stores repositories |
| Installed on computer | Accessed through browser |

## Commit

---

## Staging Area

A temporary area where files are prepared before committing.

---

## Push

Uploads commits from your local repository to GitHub.

---

## Pull

Downloads the latest changes from GitHub.

# Best Practices

- Commit frequently.
- Write meaningful commit messages.
- Keep repositories organized.
- Never upload passwords or API keys.
- Always use a .gitignore file.
